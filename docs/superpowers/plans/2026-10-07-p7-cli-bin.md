# P7 — Binário `memory` (wiring CLI end-to-end)

> Tasks usam checkbox `- [ ]`. Gates: `cargo test`, `cargo clippy --all-targets -- -D warnings`, `cargo fmt --check`.

**Goal:** Tornar a migração Rust executável end-to-end: um binário `memory` que compõe os adapters reais (Vault fs + SqliteStore + FtsSearch + MarkdownParser + NvidiaEmbed via env) sobre o `Application`, sem tocar a arquitetura congelada.

**Escopo mínimo (confirmado):** `init`, `create`, `read`, `search`, `sync`, `watch`, `stats`, `doctor`, `reindex [--force]`.

**Fora de escopo:** MCP server, `exec`, `reflect`, `adr`, `project`, config wizard, batching de embeddings, otimizações. Restrições da P6.5 mantidas (sem alteração de contratos públicos).

**Arquitetura:** `bin → Application → ports → infra`; o bin **compõe** (`main.rs` é o único lugar onde core+infra se encontram). `FsConfigStore` e `ProcessRunner` são adapters novos e finos na infra.

## Task 1: Adapters finos na infra

**Files:** Modify `crates/second-brain-infra/src/config.rs` (add `FsConfigStore`), create `crates/second-brain-infra/src/runner.rs` (add `ProcessRunner`), `lib.rs` exports.

- `FsConfigStore { path }`: `load()` lê `memory.config.json` (Não-existe → `Ok(Value::Object({}))` vazio = defaults); `save()` escreve atômico (temp+rename).
- `ProcessRunner`: `std::process::Command` com args/env/timeout_ms (kill em timeout via `try_wait` loop).
- Testes unitários mínimos (load/save round-trip; runner ok/erro/timeout).

## Task 2: Crate `second-brain-bin`

**Files:** Create `crates/second-brain-bin/Cargo.toml`, `src/main.rs`; workspace `Cargo.toml` members.

- `main() -> ExitCode`: argv → `run(args, cwd)` → imprime em stdout/erros em stderr (exitCode 1).
- `run` testável: recebe args + cwd; retorna `Result<String, AppError>` (sem print) — testes rodam contra tempdir com o `run` real e adapters reais (Vault/Sqlite/FtsSearch/Parser), embedder ausente por default em testes.
- `NullEmbed` local no bin (`is_available=false`, `embed→Err`) para modo sem chave NVIDIA.
- Config: ler `memory.config.json` do cwd via `FsConfigStore`; defaults: `vault=<cwd>/vault`, `db=<platform default>` (`resolve_default_db_path`); merge via `Config` (core) + `validate`.
- Comandos: init / create / read / search / sync / watch / stats / doctor / reindex.

## Task 3: `watch` wiring

- `app.sync()` inicial (respeitando `index_on_startup`), depois `Vault::new(vault_path).watch(callback→tx)`; loop main: `recv_timeout(1s)` → `app.apply_vault_event`; Ctrl-C mata o processo (sem graceful hook por ora).

## Task 4: Gates + registro

- Integration tests do bin (tempdir vault + tempdb; nunca vault real).
- `cargo test`, clippy `-D warnings`, fmt.
- Registro no `migration-log.md` (P7); marcar tarefas.
